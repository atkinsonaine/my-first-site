Flexbox Example

Flexbox arranges items in a row or column. Like a parent container holding child elements, these 2 cards are arranged in a row using display: flex.

Flexbox

In a flexbox it will contain:

  • display: flex; padding: 16px;
  • gap: 16px;
  • flex-direction: row;

Uses of Flexbox for responsive layouts

  • Learning flexbox taught me how to line my website up and set my navigation links horizontally or vertically.
  • Using flexbox also taught me how to align items and distribute space evenly like a book shelf.

Example: This Current Page Will Not Fit on a Phone

In this example, the layout I created intentionally fixes the box at 1500 pixels wide and adds no CSS @media query. With phone screens being much narrower, part of the example goes off-screen and requires sideways scrolling. This demonstrates how a website may look less polished, less user-friendly, and less accessible without responsive design. We can use CSS @media queries to make a layout cleaner and more user-friendly for all devices.
